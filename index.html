🧠 Scientific Conclusion

A dataset containing 90,836 Near-Earth Objects was analysed using machine learning and statistical techniques. Approximately 9.73% of the objects were classified as potentially hazardous.

A Random Forest classifier achieved 91.93% accuracy in hazard prediction using asteroid physical and orbital characteristics.

The results demonstrate how machine learning can support planetary defense and asteroid monitoring efforts.
