# 🚨 Near-Earth Asteroid Risk Analysis & AI

## Overview

This project analyzes 90,836 Near-Earth Objects (NEOs) using real NASA asteroid data and machine learning techniques.

The goal is to investigate asteroid characteristics, identify potentially hazardous objects, and evaluate how physical and orbital properties contribute to hazard classification.

---

## Dataset

Source: NASA Near-Earth Object Dataset

Objects Analysed: 90,836

Features:
- Estimated Diameter
- Relative Velocity
- Miss Distance
- Absolute Magnitude
- Hazard Classification

---

## Machine Learning

Model:
- Random Forest Classifier

Performance:
- Accuracy: 91.93%

---

## Results

- Hazardous Objects: 8,840
- Hazardous Percentage: 9.73%
- Top-risk asteroids identified using a custom risk metric.
